# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions is expected to follow it.

In short: be respectful and welcoming, accept feedback gracefully, and focus on what's best for the people using the project. Harassment, personal attacks, trolling and publishing other people's private information are not acceptable.

## Reporting

If someone's behaviour concerns you, report it privately to the maintainers through GitHub's **Report content** option on the comment or issue, or by contacting a maintainer listed on the repository. Reports are kept confidential, and maintainers will act on them as described in the Covenant's enforcement guidelines.
